Create a modern, interactive AI Agents Platform with the following requirements:

OVERVIEW:
Build a full-stack web application that showcases and allows users to interact with multiple AI agents. The platform should have a sleek, modern UI with agent cards, interactive chat interfaces, and real-time testing capabilities.

TECH STACK:
- Frontend: React with TypeScript, Tailwind CSS for styling
- Backend: Python Flask API
- UI Components: Shadcn/ui or Material-UI for modern components
- State Management: React Context or Zustand
- Icons: Lucide React or React Icons

FEATURES TO IMPLEMENT:

1. LANDING PAGE:
   - Hero section with platform title "AI Agents Platform"
   - Grid display of available agents (2 agents initially: Basic Agent 🤖 and JIRA Agent 🎫)
   - Each agent card should show: logo, name, description, status badge, capabilities list, and "Try Agent" button
   - Responsive design (mobile, tablet, desktop)
   - Dark mode toggle
   - Filter/search functionality for agents

2. AGENT DETAIL PAGE:
   - Full agent information: capabilities, tools, LLM providers, configuration requirements
   - Interactive "Test Agent" section with chat interface
   - Tabbed interface: Overview, Tools, Configuration, Documentation, API Info
   - Copy-to-clipboard for code snippets and API endpoints
   - Visual indicators for required vs optional settings
   - Credential management UI (mock - security warning displayed)

3. INTERACTIVE CHAT INTERFACE:
   - Chat window with message history
   - Input field with send button
   - Display agent responses with proper formatting
   - Loading states and typing indicators
   - Support for markdown rendering in responses
   - Session management (maintain conversation context)
   - Example prompts as quick-start buttons
